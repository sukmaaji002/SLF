# Daftar Simak SLF

After each completed change to this project, verify it, commit the files for that task, and immediately push the commit to `origin/main` at `https://github.com/sukmaaji002/SLF.git`. Confirm the push before reporting the change as complete. The repository owner has authorized this recurring push.

Keep unrelated edits, local inspection data, photos, filled forms, and credentials out of these commits. Use a normal fast-forward push. If GitHub rejects a push, inspect the remote changes and resolve the issue without overwriting anyone else's work.

The local Windows task `SLF Auto Push` also commits and pushes manual edits on `main`. If it already committed the task's changes, verify the GitHub commit and skip creating another commit. Its local log is `.git/slf-autopush.log`.
